# Proyecto de tesis de Transportes y Conservación Vial

Relación entre el espesor del afirmado y el deterioro superficial del camino vecinal Limabamba-Challhuayacu, Amazonas, 2026.

## Compilación

El archivo principal es `main.tex`. Selecciona XeLaTeX en el editor o ejecuta `latexmk -xelatex main.tex` desde la raíz del proyecto. La plantilla usa Times New Roman cuando está instalada y Tinos para previsualización.

Los estilos y las instrucciones internas corresponden a la plantilla de producción v8.
